Boomer Progress Log
Date: 2026-05-19

Project Direction
- Building Boomer as a text-to-image latent flow model project inside the current Boomer folder.
- Flame remains the future training framework/library direction.
- Sana is the main image-generation reference.
- Current v0 stack:
  - Image latent autoencoder: mit-han-lab/dc-ae-f32c32-sana-1.1-diffusers
  - Text encoder: google/gemma-4-E2B-it
  - Resolution: 512
  - Latent shape: [32, 16, 16]
  - Text embedding shape: [300, 1536]
  - Precision: BF16

Known Working Commands
1. Single-image cache proof:
   python -m boomer.sana_latent_cache \
     --image /content/test.jpg \
     --caption "a detailed caption for the image" \
     --out /content/drive/MyDrive/Boomer/cache/debug/sample.pt \
     --decoded-out /content/drive/MyDrive/Boomer/cache/debug/reconstruction.png \
     --hf-token true

2. Inspect one cache record or cache directory:
   python tools/inspect_latent_cache.py /content/boomer_debug_cache --batch-size 4

3. Inspect HF image-text dataset:
   python tools/inspect_hf_dataset.py \
     --dataset BLIP3o/BLIP3o-Pretrain-JourneyDB \
     --split train \
     --streaming \
     --save-image /content/drive/MyDrive/Boomer/cache/debug/hf_sample.png

4. Cache 32 debug records locally:
   python tools/cache_hf_dataset.py \
     --dataset BLIP3o/BLIP3o-Pretrain-JourneyDB \
     --split train \
     --streaming \
     --limit 32 \
     --out-dir /content/boomer_debug_cache

5. Overfit LatentDiT:
   python tools/overfit_latent_dit.py \
     --cache /content/boomer_debug_cache \
     --steps 200 \
     --batch-size 4 \
     --save /content/boomer_debug_latent_dit.pt

6. Longer debug training with previews:
   python tools/overfit_latent_dit.py \
     --cache /content/boomer_debug_cache \
     --steps 2000 \
     --batch-size 4 \
     --lr 3e-4 \
     --log-every 20 \
     --loss-window 100 \
     --log-csv /content/boomer_train_debug/loss.csv \
     --save-every 500 \
     --checkpoint-dir /content/boomer_train_debug/checkpoints \
     --preview-every 500 \
     --preview-cache-record /content/boomer_debug_cache/00000000_d8dfa99fb3d6.pt \
     --preview-out-dir /content/boomer_train_debug/previews \
     --preview-t 0.3 \
     --preview-steps 8 \
     --hf-token true \
     --save /content/boomer_train_debug/latent_dit_final.pt

Sana-style Flow Update
- Checked the local Sana repo to see what Sana does differently from our tiny baseline.
- Key Sana pieces identified:
  - DC-AE f32c32 VAE with scaling factor 0.41407.
  - Gemma text encoder with y_norm enabled and y_norm_scale_factor = 0.01.
  - Rectified/flow objective with target velocity = noise - clean_latent.
  - Flow shift = 3.0.
  - Logit-normal timestep sampling.
  - CFG text dropout = 0.1.
  - Grad clip = 0.1.
  - Much larger transformer capacity than our 11.7M debug model.
- Built boomer/sana_flow.py:
  - shift_sigma and unshift_sigma helpers.
  - logit-normal / uniform / high / low sigma sampling.
  - shifted inference sigma schedules.
  - shifted denoise sigma schedules.
  - Sana-style RMS normalization for cached Gemma hidden states.
- Updated tools/overfit_latent_dit.py:
  - Added --t-sampler logit-normal.
  - Added --flow-shift, --logit-mean, --logit-std.
  - Added --y-norm and --y-norm-scale-factor.
  - Added --grad-clip.
  - Saves all Sana-style settings into checkpoint train_args.
  - Denoise previews now use the shifted reverse schedule and y_norm when enabled.
- Updated tools/sample_latent_dit.py:
  - Sampling now uses the checkpoint flow shift automatically.
  - Euler and Heun now integrate over the shifted sigma schedule.
  - Sampling automatically applies y_norm if the checkpoint was trained with it.
- Updated tools/denoise_cached_latent.py:
  - Uses checkpoint flow shift and y_norm automatically.
  - Denoise grid remains useful for checking high-noise quality at t = 0.8 / 0.95.
